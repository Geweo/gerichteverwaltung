## 🔄 Was fehlt: API-Client-Generierung

### Problem

1. **Backend-Endpoints sind implementiert**, aber:
   - Swagger/OpenAPI Schema muss aktualisiert werden (automatisch)
   - API-Clients müssen generiert werden (`pnpm generate:api`)
   - Frontend-Code verwendet noch `customInstance` direkt statt generierte Clients

2. **Aktueller Frontend-Code:**
   ```typescript
   // ❌ Direkter customInstance-Aufruf (useRecipeGeneration.ts)
   const result = await customInstance<MealPlanResult>({
     url: '/api/recipes/generate',
     method: 'POST',
     data: { ... }
   });
   ```

3. **Sollte sein:**
   ```typescript
   // ✅ Generierte Client-Hooks verwenden
   const { mutate: generateRecipes } = usePostRecipesGenerate();
   ```

### Phase 2: Frontend-Code refactoren

#### Schritt 2.1: useRecipeGeneration Hook refactoren
**Aktuell:** Verwendet `customInstance` direkt  
**Ziel:** Verwendet generierte TanStack Query Hooks

**Vorher:**
```typescript
// useRecipeGeneration.ts
const result = await customInstance<MealPlanResult>({
  url: '/api/recipes/generate',
  method: 'POST',
  data: { ... }
});
```

**Nachher:**
```typescript
// useRecipeGeneration.ts
import { usePostRecipesGenerate } from '@/generated/api/recipes/recipes';

const { mutate: generateRecipes, isPending, error } = usePostRecipesGenerate();
```

#### Schritt 2.2: Neue Hooks für Queries erstellen
**Neue Hooks erstellen:**
- `useRecipesQuery(groupId, filters)` → `useGetRecipes()`
- `useRecipeByIdQuery(id)` → `useGetRecipesId()`
- `useMealPlansQuery(groupId, filters)` → `useGetMealPlans()`
- `useMealPlanByIdQuery(id)` → `useGetMealPlansId()`

**Beispiel:**
```typescript
// src/features/recipes/hooks/useRecipes.ts
import { useGetRecipes } from '@/generated/api/recipes/recipes';

export function useRecipes(groupId: number, filters?: {
  tagIds?: number[];
  searchTerm?: string;
  skip?: number;
  take?: number;
}) {
  return useGetRecipes({
    groupId,
    tagIds: filters?.tagIds,
    searchTerm: filters?.searchTerm,
    skip: filters?.skip,
    take: filters?.take,
  });
}
```

    └── ...

    queryKey: ['recipes', params],

    ...options,
  });
